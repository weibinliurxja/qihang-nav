1 · 设计令牌

令牌是唯一允许出现在代码里的硬编码值来源。禁止在组件里直接写十六进制色值或魔法数字，一律引用变量。

R-1.1

颜色只用 8 个语义槽

品牌蓝、主墨色、正文深、正文、次级、弱化、分隔线、白。新增颜色必须先在令牌表登记并说明用途，不允许"就这一处用一次"。

R-1.2

光晕必须是 radial-gradient，不能用大半径 blur

radial 自带柔和衰减，成本接近零；filter: blur() 做光晕会强行开一层离屏合成，移动端直接掉帧。

R-1.3

光晕透明度是浅底专属值

浅色底上低透明度光晕等于没画。这三个 @38% / @32% / @26% 是为浅底调过的，若哪天换深色底，必须重调而不是直接复用。

R-1.4

填充不透明度必须在 50%–65% 之间

低于 50% 在浅底上玻璃会整个消失；高于 65% 就变成实心白块，模糊白做了。三档正好卡在这个区间。

R-1.5

描边只能是白色高不透明度，不能改深色

那圈 1px 白边是"玻璃边缘折射"的视觉代理。改成灰或深色，透明感当场消失，只剩一个毛边方块。

R-1.6

投影必须用带蓝的黑，不能用纯黑

统一用 rgba(10,22,40,.08~.10)（即 #0A1628 的透明度变体）。纯黑投影落在浅色渐变上会发脏，这是浅色化后最容易翻车的一处。

R-1.7

禁止玻璃叠玻璃

搜索框位于头部面板内部，它不再加 backdrop-filter。做法是不透明白 85% + rgba(10,22,40,.07) 细描边。嵌套的 backdrop-filter 既贵又容易在 Safari 上出渲染错误，用不透明填充 + 描边把层级区分出来即可。

2 · 玻璃实现规则

2.1标准写法

/* 卡片档：站点卡 / 分类卡 */
.glass-card {
  background: rgba(255,255,255,.60);
  border: 1px solid rgba(255,255,255,.90);
  border-radius: 20px;
  backdrop-filter: blur(24px) saturate(160%);
  -webkit-backdrop-filter: blur(24px) saturate(160%);
  box-shadow:
    inset 0 1px 2px rgba(255,255,255,.70),
    0 12px 32px rgba(10,22,40,.08);
}
R-2.1

saturate 必须加

画布上的 BACKGROUND_BLUR 只表达"模糊半径"，浏览器里对应 blur(Npx)，1:1 映射。但真实玻璃还有一层色彩提纯，靠 saturate(160%) 补。只用 blur 会得到一个灰蒙蒙的毛边块，不是玻璃。

R-2.2

内阴影写进 box-shadow，别用伪元素

inset 0 1px 2px rgba(255,255,255,.7) 就是画布上那条顶部高光边。用 ::before 叠一层会破坏 backdrop-filter 的合成层，出现边缘断裂。

R-2.3

backdrop-filter 元素总数上限 12

当前页共 16 个玻璃容器（1 面板 + 6 热门卡 + 8 分类卡 + 1 页脚），已经是上限。再加玻璃元素必须先合并或降级，否则中低端设备滚动会明显掉帧。

R-2.4

降级：不支持 backdrop-filter 时退成不透明白

/* 渐进增强，不支持时是不透明白卡，不是透明色块 */
@supports (backdrop-filter: blur(1px)) {
  .glass-card { background: rgba(255,255,255,.60); backdrop-filter: blur(24px) saturate(160%); }
}

默认样式写 rgba(255,255,255,.92)，支持时再覆盖成 .60。绝不能让它降级成"半透明但没模糊"——那是全页最丑的状态。

R-2.5

光晕层不可滚动、不接收事件

三个光晕用 position: fixed; pointer-events: none; z-index: 0，内容层 z-index: 1。如果光晕跟着页面滚，玻璃的模糊结果会持续变化，滚动时整页像在抖。

R-3.1

宽度全部由栅格算出来，不写死

内容区 1200；热门卡 calc((1200 - 5×12) / 6) = 190；分类卡 calc((1200 - 3×12) / 4) = 291。卡片宽度用 grid 的 1fr，不要写 190px/291px 固定值，否则窄屏直接溢出。

R-3.2

头部面板的内缩必须补偿

外层左右内边距 24 + 内层左右内边距 96 = 120，正好等于其他区块的页面边距。改任何一边，内层的 Logo 和搜索框就会和下方网格错位。这两个数字是联动的。

R-3.3

分类卡内链接列表固定 2 列

卡内可用宽 259（291 − 16×2），链接项 124 × 2 + 间隙 10 = 258。链接名长度必须能塞进 124px——超过 5 个汉字要么缩字号要么截断加省略号，不允许撑开卡片。

R-3.4

同行卡片高度必须一致

用 align-items: stretch，不在卡上写固定高度。上一版就是中英混排导致「生活服务」卡矮了 14px，靠写死高度才对齐的——正确做法是让网格拉伸。

4 · 组件规格

4.1顶部工具条

高 34，透明底，两端对齐。左组：设为首页 / 手机版 / 加入收藏 / 意见反馈，12px L4，间距 20。右组：简体中文 / 1×12 分隔线 / 登录（品牌蓝 Medium）/ 注册，间距 16。

R-4.1

工具条不能有背景色

深色版它是 #0F1F3D 实心条，浅色版已去掉填充。加了底就和上方壁纸割裂，玻璃的整页感就断了。

4.2头部悬浮面板

高 212、圆角 28、玻璃「面板档」，内边距上下 16 左右 96。内含：品牌行（高 60）+ 搜索区（自适应）。

  • Logo：34×34 圆角 10 蓝色渐变方块（#4D8CFF → #0556B2，180deg）+ 内嵌 20×20 白色四角星；右侧「启航导航」20px/600 #0A1628，间距 10
  • 主导航：7 项，14px，间距 26。当前项品牌蓝 600，其余 #46566E Medium
  • 账户区：登录 13px #46566E + 注册按钮（胶囊，白底、13px/600 #014DB2、内边距 7×16）

R-4.2

搜索按钮的彩色投影是刻意的

用品牌蓝自身做投影（@30%），让按钮从玻璃面板里"顶"出来。这是全页唯一一处彩色投影，别推广到其他地方。

4.4热搜胶囊

左侧标签「热门搜索」12px L4，胶囊：12px #33415A、内边距 12×5、圆角 9999、填充白 55%、描边白 90%、间距 10。

R-4.3

胶囊必须带描边

胶囊坐在头部面板（白 62%）上，只靠填充区分不出来。那圈白 90% 的描边是它唯一的边界，去掉就糊成一片。

4.5区块标题行

左组：4×18 圆角 2 品牌蓝色块 + 标题（18px/600 #0A1628）+ 副标题（12px #5A6B85），间距 10。右侧可选动作（如「换一批」：14×14 刷新图标 + 12px L4 文字，间距 6）。

R-4.4

标题行一律左对齐

标题组是单子节点的 hug 容器，父级若设 SPACE_BETWEEN 会把它顶到中间。父级用 flex-start，右侧动作靠 margin-left: auto 推过去。

4.6热门站点卡

190 宽（网格自适应）、最小高 125、内边距 14、圆角 20、玻璃「卡片档」。结构：站点标识 40×40 圆角 10（品牌色底 + 16px 白色首字）→ 站点名 14/600 L1 → 描述 12/400 L3，竖向间距 10。右上角 14×14 外链箭头，绝对定位 top 14 / right 14，描边 L5。

R-4.5

6 张热门卡不做同高

热门卡是自由内容卡，高度由文案行数决定，网格用 align-items: start。不要为了对齐把描述截断——观感和信息完整度都输给那几像素的齐整。

4.7分类卡

291 宽、高 166、内边距 16、圆角 20、玻璃「卡片档」。结构：标题行（4×16 分类色块 + 分类名 15/600 L1 + 右侧「更多」+ 12×12 箭头）→ 链接列表（wrap，2 列，间隙 10）。

链接项宽 124，高自适应：22×22 圆角 6 分类色方块（11px 白色首字）+ 13px L3 链接名，间距 7。分类卡高度由内容撑，网格拉伸对齐。

4.8页脚

全宽玻璃「横条」档：填充白 50%、描边白 85%、模糊 40、无圆角，内边距 28/120、行距 18。内容三层：友情链接行（标签 12px #5A6B85 + 6 条友链 12px #46566E，间距 18）→ 1px 分隔线 rgba(10,22,40,.10) → 底部行（左：5 条帮助链接 12px #46566E 间距 20；右：版权 12px #5A6B85）。

R-4.6

页脚全宽不设圆角

它压在页面底部边缘，圆角反而会露出底下的壁纸。保留四边描边是画布上的选择，Web 上建议只留顶边 1px 白 85%。

R-5.1

全部内联 SVG，禁止图标字体

描边类图标统一 stroke-linecap/linejoin: round，fill: none，currentColor 取色。不允许用 emoji 或字符（→ ↗ ×）凑数——不同系统下字形和基线全不一致。

R-5.2

站点标识是"色块 + 首字"，不是 favicon

拿不到真实 favicon 时的正式方案：分类识别色圆角方块 + 白色首字（热门卡 16px/600，分类卡 11px/600）。不要改成灰色占位框，也不要外链第三方图标服务（会引入请求依赖和隐私问题）。

R-6.1

过渡统一 160ms / cubic-bezier(.2,.8,.3,1)

只过渡 transform / background / border-color / box-shadow。不要对 backdrop-filter 做过渡，浏览器每帧重算整块模糊，直接卡死。

R-6.2

键盘可达性

所有链接和按钮必须是真 <a> / <button>；焦点态用 outline: 2px solid #014DB2; outline-offset: 2px，不允许 outline: none。玻璃卡片的 hover 上浮必须能通过 :focus-visible 同样触发。

8 · 命名与工程组织

CSS 变量名与令牌一一对应，不允许出现未登记的变量：

/* 颜色 */ --color-brand / --color-ink / --color-ink-2 / --color-ink-3 / --color-ink-4 / --color-line
/* 分类识别色 */ --cat-news / --cat-video / --cat-shop / --cat-social / --cat-finance / --cat-tool / --cat-read / --cat-life
/* 玻璃 */ --glass-card-* / --glass-panel-* / --glass-bar-*（fill / border / blur / shadow 各一条）
/* 尺寸 */ --radius-s:6 · --radius-m:10 · --radius-l:20 · --radius-xl:28 · --space-* · --page-x:120

类名用「区块 + 元素」两段式，不用 BEM 的 __：.topbar .hero .hero-panel .search-box .search-btn .chip .card .card-cat .site-link .block-head .footer。

R-8.1

站点数据必须走配置，不写死在模板里

48 个站点 + 分类 + 识别色是一份 JSON：{ category, color, sites: [{ name, desc, url }] }。分类色由数据里带出来，不要在第 5 个分类卡上写第 5 个颜色——上一版 8 个分类卡就是 8 组独立图层，改一次要动 8 处。

R-8.2

玻璃卡片必须是同一个组件

热门卡和分类卡共用 .glass-card 基类，只覆盖内边距和网格跨度。禁止复制样式块。

9 · 验收清单

  • 1440 宽下内容区正好 1200，左右边距 120，无横向滚动条
  • 头部面板内缩后，Logo 左边缘与下方卡片左边缘严格对齐（同一条 120 竖线）
  • 玻璃卡片：能看到底下的渐变与光晕，且卡片边界靠白描边可辨
  • 搜索框与头部面板之间有清晰边界（不是两块白糊在一起）
  • 全页无一处「白字落在浅色玻璃上」
  • 同行卡片等高；分类卡内 6 个链接排成整齐 2 列，无 1 列 5 行的残缺行
  • 页面滚动时背景光晕不动，玻璃不闪烁
  • 键盘 Tab 能走完全部链接，焦点框可见
  • 禁用 backdrop-filter（DevTools 里关掉）后，卡片是不透明白卡而非透明色块
  • 移动端 375 宽下：无溢出、无文字截断、滚动帧率不低于 50fps
  • 页面里搜不到任何硬编码色值（除 CSS 变量定义处）

10 · 已知坑（踩过，必须避开）

P-1

浅底上的白字会整块蒸发

从深色版翻浅色时，「热门推荐」和「分类导航」是两套结构完全一样的标题行。按区块推进改色，只改了前者，分类标题留在原地当白字 —— 浅底上直接看不见，只有截图才发现。
做法：按「角色」清点（标题几处、副标题几处、箭头几处），逐一配 id 改完销账；改完第一张图专门找"哪块不见了"，不是看"好不好看"。

P-2

白玻璃叠白玻璃 = 边界消失

搜索框原本白 78% 叠在面板白 62% 上，两者糊成一片，完全看不出搜索框在哪。层级内的元素必须靠不透明度差 + 描边区分，不能都靠模糊。

P-3

浅色底上用大黑投影会发脏

深色版的 rgba(0,0,0,.35) 0 16px 40px 直接搬到浅色版，卡片下面像糊了一块灰。浅色版投影必须同时降不透明度（≤.12）和缩半径，并换成带蓝的黑。

P-4

中英混排会导致卡片高度不齐

「生活服务」四个汉字和「12306」「WPS」的基线、行高不一致，同规格卡片能差出 14px。解决办法是让网格拉伸等高（R-3.4），不是逐张写死高度。

P-5

单子节点的标题行会被父级居中

标题组只有一个 hug 子节点时，父级设两端对齐会把它顶到水平中间。浅色改造时踩过一次，父级一律 flex-start。

P-6

改图标颜色不能改整段 svg 属性

（设计稿侧）给图标节点直接更新 svg 属性会静默失败。SVG 展开后颜色存在子矢量节点上：实心图形改 fills，描边图标改 strokes，圆形是 ELLIPSE 节点。只改颜色，不动 strokeWeight。

11 · 设计稿侧规则（画布）

  • 所有间距取 4 的倍数，卡片宽度由栅格算出，不允许手拖
  • 图层命名「角色-内容」，如 站点名-哔哩哔哩、分类卡片-财经股票，不允许出现 Frame 123、Rectangle 45 这类默认名
  • 重复结构（8 个分类卡 × 6 链接）在画布上仍保持独立图层，但必须遵守同一套间距与圆角，方便后续组件化
  • 任何颜色改动都必须同步本文件第 1 节的令牌表
  • 下一版建议：把第 1 节全部令牌做成画布变量（颜色 / 圆角 / 间距三组，各含 Light 模式），实现深色浅色一键切换，而不是维护两份画稿
