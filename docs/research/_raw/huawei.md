## 华为云（FunctionGraph / 云托管）

**一句话结论**：华为云 FunctionGraph 有"每月刷新"的长期免费额度（每月 100 万次调用 + 400,000 GB-秒执行时间 + 5,000 次函数流节点），官方计费文档未限定新用户；但持久化存储必须另购 SFS/SFS Turbo/OBS，且中国站必须实名认证，因此"纯免费长期跑带持久化的应用"可行但持久化那部分要花钱。

- **免费额度（具体数字）**
  - **请求次数**：每月 **100 万次**免费请求（`<=100万次/月，不计费`；超出部分按每 100 万次单价计费）。免费额度为**子主账户共同使用**，跨 region、跨函数的调用次数**合并计算**。
  - **计量时间（执行时间）**：每月 **400,000 GB-秒**免费执行时间。折算成秒：内存 1 GB 时 400,000 秒；512 MB 时 800,000 秒；128 MB 时 3,200,000 秒（公式 `1024*400,000/X` 秒，X 为内存 MB）。预留实例"开启空闲模式"时，**空闲期间产生的计量时间不计入**这 400,000 GB-秒免费额度。
  - **节点执行次数（标准函数流）**：每月 **5,000 次**免费。
  - **磁盘（临时存储）**：**512 MB 规格免费**；超过 512 MB 的磁盘规格按 GB-秒计费。
  - **函数依赖包**：不计费。
  - **重要规则**：免费额度**不会按月累积**——每个自然月开始时，上月未使用的免费额度**清零**，重新计算（来源：计费说明《免费额度》，更新时间 2025-09-05）。
  - 免计费门槛（计费项页原文）：请求次数 `<=100万次/月，不计费`；执行时间 `<=400,000GB-秒，不计费`；节点执行次数 `<=5000次/月，不计费`。
  - **冷启动时间不计量、不付费**（官方 FAQ 明确）。
  - **GPU 计量时间、磁盘计量时间、闲置内存计量时间**属于**新计费项**，**不在**上述免费额度内（GPU/磁盘/闲置内存单独计价）。
- **持久化存储**：**有，但需另行购买**
  - FunctionGraph 单个函数自带 **512 MB 临时存储（/tmp）**，官方定义其**生命周期与函数实例相同**："若函数在长时间内未收到请求，系统将回收该实例，此时磁盘上的数据将随之消失"——即 **/tmp 不是持久化存储**。
  - 官方支持的持久化挂载：**SFS Turbo 文件系统**、**通用文件系统（SFS）**、**ECS 共享目录（NFS）**；**SFS 容量型仅存量用户可用**。官方存储选型表明确标注 SFS Turbo / OBS / ECS 共享目录为"**持久**"，临时存储为"**临时存储**"。
  - 也可用 **OBS 对象存储**（对象存储，持久，`OBS 计费概述`单独计费）。
  - 结论：**FunctionGraph 本身不提供免费持久化磁盘**；持久化要么挂 SFS/SFS Turbo（按文件系统计费），要么用 OBS（按存储/请求计费），都**不包含在 FunctionGraph 免费额度内**（计费项"其他费用"条目：搭配 OBS、SMN 等需为该服务额外付费）。
- **数据存活（重启/休眠/不活跃）**
  - 函数代码、配置、依赖包、镜像等**控制面资源持久存在**。
  - 运行时本地数据：/tmp 与实例绑定；**长时间无请求 → 实例被回收 → 磁盘数据消失**。若持续有请求，实例保持存在，先前写入磁盘的数据会保留（但这不构成持久化保证）。
  - 因此"不活跃后数据存活"对本地磁盘是 **否**；要存活必须落 OBS/SFS。
- **是否免费到永远**：**属于"长期每月免费额度"，但官方保留调整权**
  - 依据：官方《计费说明 · 免费额度》原文为"**每个月您都能免费使用一定额度的函数工作流服务**"，措辞是全量用户、按月循环，**没有任何"新用户""首次""试用期"限定**；该页更新时间 **2025-09-05**，说明 2025 年仍在执行。计费概述页亦写"函数工作流**每个月**会给您免费提供一定额度的函数工作流服务"。
  - 需要注意：活动规则页明确"华为云有权根据业务需求，随时调整……试用规则等"。这属于任何云厂商的通用免责，不等于额度已被取消；就**已抓取的官方文档而言，2026 年仍写有每月免费额度**。
  - **免费试用（trial）与每月免费额度是两个概念**：华为云"免费体验中心"的免费试用**仅限新用户**（见下条）；而 FunctionGraph 这 100 万次 + 400,000 GB-秒是逐月刷新的常设额度。
- **试用额度**：**免费体验中心确实只对新用户**
  - 官方《免费体验活动规则》（更新时间 2025-06-10）参与对象三条硬性条件：**① 完成个人实名认证或企业实名认证；② 未购买、未试用过相应类型的华为云产品；③ 新用户专享限用户等级为 V0**（V0 = 账户下不存在预付费 >0 的历史订单，且不存在后付费 >0 的账单）。
  - 同一用户对同一产品**仅能申请 1 次**；有未支付订单/欠费会审核不通过；试用到期后需续费或关停，否则可能产生费用与数据损失。
  - FunctionGraph 产品页把"免费试用"直接写成"**函数每月前 100 万次调用免费**"，指向的正是常设的每月免费额度，而非一次性资源包；**未找到** FunctionGraph 单独的"新用户试用资源包"官方说明。
- **是否需要信用卡**：**中国站不需要，但必须实名认证 + 先充值**
  - 官方《中国站与国际站的差异》（更新时间 2026-06-22）：**中国站"购买或使用云服务区资源必须通过实名认证"**；"交易准备 = 通过实名认证"；**交易模式为预付费（先充值后消费）**；支付方式为"充值：银行转账、在线支付；支付：余额支付、在线支付"，且注明"**支持微信、支付宝、银联支付**"。**未出现信用卡/绑卡要求**。
  - 对照：**国际站**"交易准备 = **绑定信用卡**或线下申请授信"，"后付费，即先消费后还款"。所以若走国际站，则需要信用卡。
  - 免费试用同样要求先完成实名认证（免费体验活动规则原文）。
  - 注册中国站需使用**中国大陆手机号**（账号中心文档原文："请使用中国大陆的手机号码"）。
- **数据存放地区**：由用户创建函数时选择的 region 决定；官方文档列出的中国大陆 region 示例包括 **华北-北京四、华东-上海一、华东-上海二、华南-广州、华北-乌兰察布一**（函数流当前仅支持华北-北京四、华东-上海一、华东-上海二、华南-广州、亚太-新加坡；通用文件系统挂载当前仅支持"华北-乌兰察布一"）。完整支持区域以官方《地区和终端节点》页面为准。
- **中国大陆可达性**：**官方证据（无实测延迟数据）**
  - 证据：华为云存在明确的"**中国站**"（适用于中国大陆客户），FunctionGraph 官方文档、产品页、控制台、备案服务均为中国站页面；官方文档列出上述中国大陆 region；FunctionGraph 支持区域指向官方 endpoint 列表。
  - **无可靠证据**说明具体延迟数字——本次调研未做本机 ping/curl 实测，故不给出任何延迟数值。
- **部署形态**：**FaaS 函数计算**；支持**代码包（ZIP/JAR）**与**容器镜像（SWR）**两种创建方式；函数类型分**事件函数**与**HTTP 函数**。容器镜像函数约束：镜像需自带 HTTP Server 且**监听端口固定 8000**（仅"中东-利雅得"支持在控制台改端口），必须实现 `/invoke`（事件函数）或直接 HTTP 触发（HTTP 函数），单个镜像最大 **10 GB**。使用 FunctionGraph **无需**自行开通/预配置计算、存储、网络服务。
  - 注意：这是"请求驱动 + 自动伸缩 + 空闲不计费"的托管函数，**不是常驻容器/长驻进程**；虽有预留实例（消除冷启动）但需单独付费。单请求最大执行时长 259200 秒（超 90 秒需异步调用），单账户并发执行数 100，函数最大内存 10 GB，单账户最多 400 个函数。华为云另有 CCE/CCI/CAE 等容器托管服务，但那是付费产品，无对应长期免费额度（本次未发现免费额度官方说明）。
- **自定义域名与备案**：**用中国大陆节点就必须备案**
  - 官方《我需要在华为云备案吗》（更新时间 2026-04-30）："**不可以**，根据《互联网信息服务管理办法》等相关规定，**使用中国大陆节点服务器开办的网站或者 App，必须先办理备案**，备案成功并获取通信管理局下发的 ICP 备案号或者备案 ID 后才能开通访问"；"我的业务是通过 IP 访问的，需要备案吗？——**需要**，只要使用中国大陆节点的服务器就需要备案"。
  - 域名可解析绑定到 API 网关/FunctionGraph 提供的入口并用自有域名，但只要落地在中国大陆 region，就须备案；解析到中国香港/中国台湾/中国澳门等非中国大陆地区则不需要备案。华为云提供**免费备案服务**（需先购买华为云备案服务器）。

- **对本需求的结论**（用户：中国大陆、无 VPS、要部署小型导航应用、需要持久化、只要免费）
  - **能否免费长期跑**：可以。用 FunctionGraph 的 **HTTP 函数**（可打包成容器镜像，或直接上传代码）承载导航应用的 API，配合 **API 网关**暴露访问；每月 100 万次调用 + 400,000 GB-秒对小型导航站几乎不可能超，超出的冷启动也不计费。
  - **持久化是唯一硬缺口**：FunctionGraph 的 /tmp 会随实例回收而丢失，**不满足"需要持久化"**。要持久化必须挂 **SFS Turbo / SFS / ECS 共享目录** 或使用 **OBS**，这些**都按各自服务单独计费，不包含在 FunctionGraph 免费额度内**——即"纯免费 + 持久化"在华为云上无法同时满足。
  - **前置成本/门槛**：必须完成**实名认证**（个人身份证即可），中国站为预付费，使用前需要充值（按需后付费部分会从余额扣），**不要求信用卡**；但账号无余额、长期零消费可能影响按需资源的可用性。
  - **备案**：若绑定自有域名并解析到中国大陆 region，**必须完成 ICP 备案**；想免备案只能解析到中国香港等境外节点（但那已不属于中国站大陆 region 的免费红利范围，且价格更高）。
  - **替代建议**：若坚持"免费 + 持久化"，更适合的方案是用 OBS 免费额度存静态数据，或考虑其他给出免费持久化存储的平台；华为云本身不免费提供持久化磁盘。
- **置信度**：**high**
  - 免费额度数字、实名认证、备案、预付费/支付方式均来自华为云官方文档且成功抓取。唯一降级项：中国站 2025-08-01 价格调整的**官方公告页未抓到**（仅国际站官方公告可抓，内容已注明）；延迟无实测数据。
