## 阿里云函数计算 FC

**一句话结论**：2026 年阿里云函数计算（FC）已没有「free forever 的每月免费额度」，新用户只有「15 万 CU/月 × 连续 3 个周期」的试用额度；持久化必须依赖 NAS/OSS 等另计费产品，生产环境还不能用默认公网域名（需备案的自定义域名）。

- **免费额度（具体数字）**
  - **无永久免费额度**。现行官方「计费概述」只列出三种方式：试用额度、按量付费、资源包（含常驻资源池包年包月），没有「每月固定免费额度」这一项。
  - **试用额度（免费试用包）= CU 试用资源包**：以「月」为周期，**连续提供 3 个周期**，**每周期 15 万 CU 使用量**；超出部分自动转入按量付费。官方原文：「每个周期超出试用额度的部分，即超出**15 万**的 CU 使用量将自动转入按量付费。」
  - 试用额度领取条件：**首次登录函数计算控制台**的用户；阿里云账户与 RAM 用户共享该额度；需在新客试用套餐页面免费领取（`planCode=package_fcfreecu_cn`）。
  - **磁盘**：512 MB 以内免费，超出部分按 0.05 CU/GB\*秒 计费（官方计费示例中明确「磁盘 512 MB 以内免费」）。
  - **公网流量**：与 CDT 相关，见下条「近期变更」。
  - 注：本次未在官方现行文档中找到旧口径「每月 100 万次调用 + 400000 GB-s」的免费额度页面（**未找到官方来源**，该口径疑为 2024-08-27 CU 改造前的历史政策）。官方现行文档中已无「免费调用次数/GB-s 永久额度」的表述。

- **持久化存储**：FC 函数实例本身**无状态**（临时硬盘/层均为实例级、非持久）。持久化需挂载：
  - **NAS（文件存储）**：支持，前提是函数已配置 VPC 网络访问；同一地域一个函数最多 5 个 NAS 挂载点 + 5 个 OSS 挂载点；仅支持 NFS 协议。自动配置会创建通用型 NAS，费用按 **通用型 NAS 计费** 另收，另涉及 VPC 相关费用。
  - **OSS（对象存储）**：支持挂载，费用按 OSS 计价另收。
  - 结论：持久化能力「有」，但**均不在 FC 的免费额度内**，属独立计费产品。

- **数据存活（重启/休眠/不活跃）**：默认最小实例数为 0 时，无请求则实例自动销毁，**不使用不收费**；实例销毁后本地磁盘内容不保留。若无请求但**最小实例数 ≥ 1**，实例进入浅休眠（原闲置）状态仍持续计费（vCPU 不收费，GPU 按活跃的 11.7%~23% 计费）。要长期保存数据必须落 NAS/OSS，否则函数冷启动后数据丢失。

- **是否免费到永远**：**否**。依据：官方现行「计费概述」/「试用额度」页写明，免费部分只有「首次开通用户、以月为周期连续 3 个周期、每周期 15 万 CU」的试用资源包，且「有效期结束后资源使用量均将转入按量付费」（计费 FAQ 原文）。官方资源包页还明确「函数计算服务本身为按量付费无到期概念」，即服务层不存在永久免费档位。

- **试用额度**：
  - **CU 试用资源包**：15 万 CU/月 × 3 个周期（约 3 个月）。
  - 起算方式：按自然月 01 日 00 时重置周期；中途领取时首月剩余天数 + 末月前半段合并算一个周期（官方举例：2024-09-15 09:00 开通，周期 1 = 09-15 09:00~09-30 24:00 + 12-01 00:00~12-15 09:00）。
  - 2024-08-27 起，新用户免费试用包由原来的 **GPU 资源包 + vCPU 资源包 + 内存资源包 + 函数调用包 4 项** 合并变更为 **CU 资源包 1 项**。
  - **公网流量**另有独立口径：CDT 普通 BGP 公网流量免费额度 **200 GB/月**（全球含中国内地 20 GB/月 + 非中国内地 180 GB/月），由含 FC 在内的 8 款产品共享、长期有效自动发放；此外曾发放的 FC 专享「每月 100 GB、有效期 3 个月（新用户）/12 个月（老用户）」额度「可继续使用，额度耗尽或到期后不再补发」。

- **是否需要信用卡**：官方文档未出现「必须绑定信用卡」的要求（**未找到官方来源**）。
  - 明确要求：**必须实名认证**。官方账号中心原文：「在购买阿里云产品或服务之前，您必须完成实名认证」「没有实名认证，您将无法购买、续费或使用大部分云服务」，依据为中国《反电信网络诈骗法》《网络安全法》；个人实名认证方式为个人支付宝认证或扫脸认证。
  - FC 自 2024-08-27 起**自动开通**：新用户完成阿里云账号注册后无需额外操作即可直接使用 FC（即开通本身不需要单独绑卡）；官方称「未实际使用的，不会产生任何费用」。
  - 计费渠道为人民币（支付宝/微信/网银等），非信用卡体系；超出试用额度后的按量付费需账户可用额度，欠费会导致服务冻结。因此「要信用卡？」填写为**否**，但**需实名认证**；是否需绑定某种支付方式以领取试用，官方页面未明示。

- **数据存放地区**：按用户选择的地域（Region）存储与运行，资源包支持跨地域抵扣。
  - **中国内地地域**（官方服务接入地址表）：华东1（杭州）、华东2（上海）、华北1（青岛）、华北2（北京）、华北3（张家口）、华北5（呼和浩特）、华北6（乌兰察布）、华南1（深圳）、西南1（成都）。
  - 其他：中国香港、新加坡、马来西亚（吉隆坡）、印尼（雅加达）、泰国（曼谷）、日本（东京）、韩国（首尔）、德国（法兰克福）、英国（伦敦）、美国（弗吉尼亚/硅谷）、沙特（利雅得，由合作伙伴运营）。

- **中国大陆可达性**：**官方证据**（无本机实测数据，不写延迟数字）。依据：官方「服务接入地址」页列出中国内地 9 个地域的公网服务接入地址，格式为 `<主账号ID>.<region>.fc.aliyuncs.com`（如 `cn-hangzhou.fc.aliyuncs.com`），并有对应内网地址；产品为中国站（aliyun.com）主力 Serverless 产品，文档与备案流程面向中国内地。未做本机连通性实测，故不提供延迟/丢包数字。

- **部署形态**：Serverless FaaS。支持事件函数与 HTTP 函数/Web 应用；触发方式含 HTTP 触发器、自定义域名、定时等；标准模式（按请求弹性）与 2025-05-15 新增的**极速模式**（按请求弹性 + 快照加速启动，百毫秒级响应，无请求时释放 vCPU）。可用 Serverless Devs、控制台、应用中心部署。

- **自定义域名与备案**：
  - 必须准备一个**已在阿里云接入网站备案**的自定义域名（中国内地地域函数）；**中国香港和海外地域绑定的自定义域名不需要备案**。
  - 需要把域名 CNAME 解析到 `<account_id>.<region_id>.fc.aliyuncs.com`（公网）或 `-internal` 内网地址；支持泛域名，不支持中文域名；绑定地域须与函数地域一致。
  - **生产环境禁止使用默认公网域名** `*.<region_id>.fcapp.run`：官方公告明确其「只能用于测试环境」，生产使用出事不在产品安全责任范围内，建议改绑自定义域名或走 ALB、云原生 API 网关。
  - 购买 100 元以上任意 CU 资源包可获**免费 ICP 备案服务码**。
  - HTTPS：自定义域名可启用 HTTPS（选阿里云 SSL 证书或手动上传 PEM），支持强制 HTTPS、TLS 版本与加密套件配置。

- **2025–2026 近期变更**：
  - **2025-05-15 0 时起**：新增**极速模式**产品形态；**调整 CU 定价**（阶梯 1 `(0,2亿]` 0.00011 元/CU、阶梯 2 `(2亿,10亿]` 0.00010 元/CU、阶梯 3 `>10亿` 0.00009 元/CU）；新增**资源包月包**（50 万 / 300 万 / 1000 万 / 2 亿 CU）。
  - **官网 8 折折扣单价**：0.000088 / 0.000080 / 0.000072 元/CU，官方标注活动时间 **2024-08-27 ~ 2026-08-27**（即至本文查证日 2026-10-01 时该 8 折活动已到期，新价需以购买页为准）。
  - 计费项统一为 **CU 使用量**（2024-08-27 起）：函数调用次数 75 CU/万次、活跃 vCPU 1 CU/vCPU\*秒、闲置 vCPU 0、内存 0.15 CU/GB\*秒、磁盘 0.05 CU/GB\*秒；GPU 各系列系数不同（Ada 1.7、Tesla 2.1、Ampere 1.8 等）。出账周期 1 小时；小时内调用 >0 且折算金额低于 0.01 元时按 0.01 元计费。
  - **公网出流量**改为统一在 **CDT** 侧计费（不再提供「公网出流量包」）。
  - 计费 FAQ 提到面向中国站中国内地地域的**夜间 5 折优惠**与 8 折优惠叠加（官方表述存在于 FAQ，具体细则以活动页为准）。
  - 生产环境默认公网域名禁令、GPU 驱动版本升级（550.54.15→570.133.20→580.95.05）、控制台导航改版等公告均在列。

- **对本需求的结论**（用户：中国大陆、无 VPS、部署小型导航应用、需要持久化、只要免费）：
  - **不满足「只要免费」**：FC 没有永久免费额度，只有 3 个月、每月 15 万 CU 的试用包；导航类应用即使流量很小，3 个月后也会转入按量付费。
  - **持久化不免费**：导航数据要留存必须挂 NAS 或 OSS（或外接云数据库），这些均独立计费；FC 自带的临时硬盘/层不是持久化方案。15 万 CU 的应用额度也完全不含存储费用。
  - **生产可用性门槛**：默认公网域名禁止用于生产，必须有已备案的自定义域名（中国大陆）或走香港/海外地域；域名备案本身需要成本与时间。
  - 综合：若接受「3 个月试用 + 之后极低成本按量付费」，FC 技术上可以部署小型导航应用；若严格「零成本永久运行 + 持久化」，FC 不符合需求，需另寻有 free forever 档位且自带持久化的方案。

- **置信度**：high（免费/试用口径、持久化、备案、地域、定价均有一手官方文档；仅「是否需绑支付方式」「旧 100 万次+400000 GB-s 口径」两处证据不足，已明确标注）
