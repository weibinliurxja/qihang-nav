## 腾讯云 EdgeOne Pages（国际版与中国站）

**一句话结论**：EdgeOne Pages（2026-06 已更名 EdgeOne Makers）免费版额度慷慨且流量/请求不限量，但免费版在中国大陆访问平台默认域名受 3 小时预览链接限制，要用稳定通道必须绑自定义域名 + 备案，而免费永久承诺目前只在国际站定价页 FAQ 明确给出。

- **免费额度（具体数字）**
  - 站点加速流量与请求：**不限量**（官方 FAQ 原文「不限量的网站安全加速流量与请求额度」），即未公布带宽/流量/请求数上限。
  - 项目数：**40 个**（按站点统计，站点下所有项目合计）。
  - 项目总存储容量：**5 GB**；单项目文件数 **20000 个**；单文件大小 **25 MB**。
  - 构建次数：**500 次/月**；并发构建数 **1**；单次构建超时 **20 分钟**；构建算力规格 **4 核 6 GB**。
  - Edge Functions：执行次数 **300 万次/月**；CPU Time **300 万 ms/月**；代码包大小 **5 MB**；请求 body **1 MB**。
  - Cloud Functions：执行次数 **100 万次/月**；总内存时长 **50 万 GB-s/月**；代码包（含依赖）**128 MB**；请求 body **6 MB**；最大执行时长默认 **30 秒**、可配置至 **120 秒**。
  - KV 存储：存储空间 **1 GB**；命名空间 **10 个/账户**；单值上限 **25 MB**；仅 Edge Functions 可用。
  - Blob 存储：存储空间 **1 GB**；单值上限 **25 MB**；Edge Functions / Cloud Functions 均可用。
  - Agents：总内存时长 **10 万 GB-s/月**，执行次数 **20 万/月**，单请求最长 **3600 秒**，会话最长空闲 **300 秒**，会话最大并发 **40 个**。
  - Sandbox：总内存时长 **10 万 GB-s/月**，最大并发 **20 个**。
  - Models 内置模型免费额度：**50 万 token/月**。
  - 自定义域名：**200 个**；免费 SSL 证书：**支持**。

- **持久化存储**：**有，且免费版内置**。KV（分布式键值，最终一致，边缘缓存最长 60s，仅 Edge Functions）与 Blob（分布式对象存储，默认最终一致、可选强一致 `{ consistency: "strong" }`，支持目录层级）各 **1 GB**。官方明确「创建免费账户后，您的文件将永久存储……没有过期日期」（Pages Drop 发布公告）。注意：KV/Blob 面向 Makers Functions 运行时数据，官方不建议把 Blob 当公网图床/CDN 用。

- **数据存活（重启/休眠/不活跃）**：官方文档**未定义休眠/缩容/不活跃回收机制**——EdgeOne Makers 是静态托管 + Serverless Functions 形态，无「实例休眠」概念，静态资源与 KV/Blob 数据持久保存。**未找到官方关于长期不活跃项目被删除的条款**（无可靠证据）。风险点仅在额度：免费版超限官方称「在推出收费版之前，即使超出免费版的用量限制也不会中断服务」。

- **是否免费到永远**：**存在官方口径冲突**。
  - 国际站定价页 FAQ 明确「免费计划会长期提供吗？**是的，我们的免费版本将永久提供！**」，且价格标注 **$0/月**。
  - 中国站文档（更新时间 2026-09-22 / 2026-06-12）表述为「当前处于**限时免费阶段**，实际额度比商业化规划值更宽松」，且「下表配额在**商业化后可能调整**」。
  - 结论：可视为「免费版长期存在」的官方承诺，但**配额数值不保证永久不变**，商业化后可能调整。

- **试用额度**：本平台**不是** trial credit 模式——无「注册送 X 美元/代金券」的通用试用额度（**未找到官方来源**）。仅有的是 **Models 模型网关限时赠送 token 额度**与 **50 万 token/月** 内置模型免费额度，属免费额度而非试用信用。国际站在注册流程中可能发放 EdgeOne 主产品（CDN/安全）试用套餐，但与本任务（Pages/Makers）无关，且未在 Makers 文档中确认。

- **是否需要信用卡**：**否**。官方 Pages Drop 发布公告原文：「**基本静态网站托管无需信用卡，没有隐藏费用**」（完全免费：无需信用卡）。定价页免费版为 $0/月，无付费前置。⚠️ 但这是针对静态托管/免费版；**未找到官方文档说明 Cloud Functions 或绑定自定义域名是否额外要求绑定支付方式**（无可靠证据）。

- **数据存放地区**：**官方文档未明确披露 Makers 平台 KV/Blob 主存储的物理数据地域**（无可靠证据）。可确认的相关事实：KV 采用「中心化存储 + 边缘缓存」架构；Cloud Functions 自 **2026-04** 起支持**选择函数部署地域**（“将函数部署到离数据源更近的区域”）；项目加速区域可选「中国大陆可用区 / 全球可用区 / 全球可用区（不含中国大陆）」。**注意本站目前无独立隐私/数据驻留条款被本次抓取到**，故无法断言数据落地国家。

- **中国大陆可达性**：
  - **官方证据（关键限制）**：官方域名管理文档明确——通过**项目域名 / 部署域名**访问 Makers 站点时，**中国大陆网络环境须使用系统生成的预览链接，该链接有效期仅 3 小时，超时后返回 401**；非中国大陆网络环境可直接访问。官方建议「绑定自定义域名以建立稳定访问通道，**全球可用区（不含中国大陆）无需备案**」。
  - **节点规模（官方 FAQ）**：EdgeOne 全球 **3200+ 个边缘节点**，其中**亚洲超 2500+**。
  - **本机实测（用户提供）**：`edgeone.app` 返回 **302**，耗时 **0.63s**；`pages.edgeone.ai` 返回 **200**，耗时 **0.10s**，均可达（非官方来源，为委派方实测数据）。
  - 综合：**平台控制台/文档站大陆可达**；但**免费默认域名在 3 小时后对大陆用户返回 401**，可用性受限。

- **部署形态**：Git 仓库导入（GitHub / GitLab / Bitbucket）、官方模板、直接拖拽上传（Pages Drop）、CLI、MCP、IDE 插件、CodeBuddy IDE、部署按钮、GitHub Actions / GitLab CI/CD / CNB 插件。支持静态站点（Astro、Hexo）、SPA（React、Vue）、全栈框架（Next.js、Nuxt、Astro、React Router、SvelteKit、TanStack Start、Vike）、Agent 应用。边缘函数 + 云端函数（Node.js / Python / Go）+ KV + Blob + 中间件 + Agent 运行时。自动 CI/CD、全球 CDN、免费 SSL。

- **自定义域名与备案**：自定义域名上限 **200 个**，支持免费 SSL 证书。**备案规则（官方原文）**：
  - 加速区域＝**中国大陆可用区**：添加自定义域名**需完成工信部备案**。
  - 加速区域＝**全球可用区**（含中国大陆）：添加自定义域名**需完成工信部备案**。
  - 加速区域＝**全球可用区（不含中国大陆）**：添加自定义域名**不要求工信部备案**。
  - 平台分配的默认域名（`*.edgeone.app` 等），在大陆访问须用 3 小时预览链接。
  - 账号层面：中国站（console.cloud.tencent.com）使用腾讯云账号体系，通过国际站（console.tencentcloud.com）注册可走国际账号。**未找到官方文档明确说明国际站是否需要实名认证**（无可靠证据）。

- **2025–2026 近期变更**（官方产品动态）：

- **对本需求的结论**：**可用但有一个硬伤**。用户场景（中国大陆、无 VPS、小型导航应用、需持久化、只要免费）与 EdgeOne Makers 的匹配度：✅ 免费、无信用卡、流量/请求不限量、有 KV+Blob 各 1GB 持久化、构建 500 次/月对小型应用充裕、有官方免费 SSL；❌ **最大问题是大陆访问平台默认域名只能靠 3 小时预览链接**，免费稳定方案只能二选一：**(A)** 绑自定义域名并把加速区域设为「全球可用区（不含中国大陆）」→ 无需备案，但流量不经大陆节点，大陆访问质量取决于境外节点（官方称亚洲 2500+ 节点，未给大陆延迟数据）；**(B)** 用中国大陆/全球含大陆加速区域 → 需 ICP 备案（无 VPS 也能备案，需要域名+腾讯云备案主体，非纯免费无门槛）。另需注意「免费永久」仅国际站明确，中国站仍写「限时免费阶段」且配额可能调整。若要长期零成本稳定服务大陆用户，EdgeOne 不是最省心的选择；若可接受自定义域名+备案，则是额度最慷慨的免费选项之一。
