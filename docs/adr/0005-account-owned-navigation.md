# 管理员创建账号，每个账号拥有独立导航配置

将共享口令改为账号密码登录，由 admin 创建和管理普通账号，不开放注册。沿用 Pages + KV，配置和图标改为按不可变账号 ID 分区，服务端只根据已认证会话选择数据空间；旧配置和旧图标仅迁移给初始 admin，并保留旧键。

使用共用认证模块、带随机盐的 PBKDF2 摘要和 HttpOnly 签名会话，重置密码或启停账号时轮换会话签名密钥。管理员可以管理凭据，但页面不提供查看其他账号配置的功能。停用替代删除，以保留配置和可恢复性。

保留整份文档读写的简洁性：不同账号不会互相覆盖，但同一账号并发编辑和多个管理员页面同时改账号表仍可能后写覆盖。KV 的最终一致性意味着跨节点的账号变更和会话撤销可能有延迟；若将来要求即时撤销或强一致并发管理，需要迁移认证状态到强一致存储。该决策替代 ADR-0002 中单用户、共享口令的假设。

参考：[Cloudflare Web Crypto](https://developers.cloudflare.com/workers/runtime-apis/web-crypto/)、[KV 一致性](https://developers.cloudflare.com/kv/concepts/how-kv-works/)。
